## 1. 概要と実験目的

本マニュアルは、体温と外気温の温度差（$\Delta T \approx 5 \sim 15^\circ\text{C}$）のみを利用し、**「マクスウェルの悪魔」フィードバック制御デバイスを完全自律動作**させる実験の組み立てから動作検証までの手順を解説します。

### 実験のポイント
1. **ハイブリッド自律給電**: USB接続で初期起動・シリアルログ確認後、USBケーブルを抜去してもダイオードOR回路（BAT54×2）により無瞬断でTEG発電蓄電へ切り替わります。
2. **ランダウアー限界の超越実証**: ESP32-C3 の Deep Sleep（~5μA）を活用し、悪魔の情報処理コストを 2〜3 桁削減することで、**正味仕事 $W_{\text{net}} > 0$** および **消去コスト係数 $\beta \approx 0.025 \ll 0.187$** を達成します。

## 3. Phase 1: ブレッドボード回路の組み立て

回路図 [circuit_diagram_D.svg](file:///home/imaken/notebook_project/Maxwells_demon/thermal_demo_design/circuit_diagram_D.svg) に基づき、ブレッドボード上に回路を組み立てます。

```
                       【構成D 全体接続ブロック図】

      [ USB 5V ] ─────(D1: BAT54)─────┐
                                      ├────► [ VCC_node ] ──► ESP32 3V3 / センサー電源
 [ TEG ] ──► [ LTC3108 ] ──(D2: BAT54)┘         │
                │                           [100μF]
                ├──► [1.0F スーパーキャパシタ]     │
                │        │                     GND
                │        ├──► [100Ω] ──► [緑LED] ──► [IRLZ44N MOSFET] ──► GND
                │        │                               ▲ (Gate: GPIO3)
                │        └──► (10k/10k 分圧) ──► GPIO0 (V_store 監視)
                │
                └───────────► (10k/10k 分圧) ──► GPIO1 (V_out 監視)

 [ DS18B20 ×2 ] ──(OneWire + 4.7kΩ)──► GPIO2
 [ 赤LED ] ◄── [330Ω] ◄─────────────── GPIO4
```

### ステップ 1-1: マイコンと電源ライン（ダイオードOR回路）の配置
1. XIAO ESP32-C3 をブレッドボードの中央上部に配置します。
2. **ダイオードOR回路**の配線:
   - D1 (BAT54): アノードを XIAO の `5V` ピンに接続し、カソードをブレッドボードの `VCC_node` ラインに挿入します。
   - D2 (BAT54): アノードを CJMCU-3108 の `VOUT` ピンに接続し、カソードを `VCC_node` ラインに挿入します。
   - 100μF 電解コンデンサの **+極** (長い足) を `VCC_node` に、**-極** (帯マーク側) を GND に接続します。
   - XIAO の `3V3` ピンを `VCC_node` ラインに接続します。

> [!CAUTION]
> **ダイオードと電解コンデンサの極性**
> - BAT54 はアノード（順方向流入口）とカソード（黒帯側）を逆に挿すと給電されません。
> - 電解コンデンサの極性を逆に接続すると破損の原因となります。

### ステップ 1-2: TEG・LTC3108・スーパーキャパシタの接続
1. CJMCU-3108 (LTC3108) モジュールのピン設定を確認します（`VS1 = HIGH`（3.3V設定））。
2. **1.0F スーパーキャパシタ** の +端子を LTC3108 の `VSTORE` に、-端子を GND に接続します。
3. **TEG (ペルチェ素子)** の 赤線 (+) を LTC3108 の `VIN+` に、黒線 (-) を `GND` に接続します。

### ステップ 1-3: MOSFET制御 & LED回路の配線
1. **IRLZ44N MOSFET** を配置します（型番印字面を手前・正面に向け、左から **1:Gate, 2:Drain, 3:Source**）。
   - **Pin 1 (Gate)**: XIAO `GPIO3` ピンから **220Ω 抵抗** 経由で接続。さらに Gate ピンと GND の間に **10kΩ プルダウン抵抗** を接続。
   - **Pin 2 (Drain)**: 緑色 LED (LED_demon) のカソード (短足) に接続。
   - **Pin 3 (Source)**: GND ラインに接続。
2. **緑色 LED (LED_demon)** のアノード (長足) を **100Ω 抵抗** 経由で `VSTORE` (1.0F キャパシタ+) に接続。
3. **赤色 LED (LED_passive)** のアノード (長足) を XIAO `GPIO4` に、カソード (短足) を **330Ω 抵抗** 経由で GND に接続。

> [!IMPORTANT]
> **MOSFETのロジックレベル確認**
> - 必ず `IRLZ44N`（Vgs(th) ≤ 2.0V）をご使用ください。`IRF540N` などの標準パワーMOSFETは 3.3V 駆動できないため動作しません。

### ステップ 1-4: ADC 電圧モニタ分圧回路の配線
1. **$V_{\text{store}}$ 電圧モニタ (GPIO0)**:
   - `VSTORE` ライン → **10kΩ** → `GPIO0` (A0) → **10kΩ** → GND
2. **$V_{\text{out}}$ 電圧モニタ (GPIO1)**:
   - LTC3108 `VOUT` ライン → **10kΩ** → `GPIO1` (A1) → **10kΩ** → GND

### ステップ 1-5: DS18B20 温度センサーの配線
1. 2本の DS18B20 プローブ型センサーの配線をまとめます:
   - 赤色線 (VCC) ×2 → `VCC_node`
   - 黒色線 (GND) ×2 → GND
   - 黄色/青色線 (Data) ×2 → XIAO `GPIO2`
2. `GPIO2` ピンと `VCC_node` の間に **4.7kΩ プルアップ抵抗** を接続します。

### ステップ 1-6: 熱電発電 (TEG) ユニットの物理セットアップ
1. TEG (SP1848-27145) の印字面（高温側 $T_{\text{hot}}$）と無地裏面（低温側 $T_{\text{cold}}$）を確認します。
2. 低温側に **熱伝導シリコングリス** を薄く均一に塗り、40×40mm **アルミヒートシンク** を密着固定します。
3. 高温側・低温側のそれぞれに DS18B20 金属プローブを熱伝導テープまたはカプトンテープで密着させます。

## 5. Phase 3: USB接続下での初期通電・キャリブレーション

### ステップ 3-1: シリアルログの確認
1. Arduino IDE の `シリアルモニタ` を開き、ボーレートを **115200 baud** に設定します。
2. マイコンのリセットボタン（または接続時自動リセット）により、以下の起動ログが出力されることを確認します:

```
════════════════════════════════════════════════════

 Configuration D: ESP32-C3 Deep Sleep (Diode-OR Hybrid) Edition
 情報エンジン検証デバイス — 超低消費電力 / ハイブリッド自己駆動版
════════════════════════════════════════════════════
...
time_s,phase,T_hot_C,T_cold_C,deltaT_C,V_store_mV,V_out_mV,flash_count,E_extracted_mJ,demon_cost_mJ,net_work_mJ,avg_power_mW
```

### ステップ 3-2: センサーおよび電圧読み取りのキャリブレーション
1. **温度センサー確認**:
   - シリアルログの `T_hot_C` および `T_cold_C` が室温（20〜25℃付近）を表示し、`deltaT_C ≈ 0.0` であることを確認。
   - `-127.0` と表示される場合は OneWire の配線または 4.7kΩ プルアップ抵抗を確認。
2. **電圧モニタ精度確認**:
   - テスター（マルチメータ）で 1.0F キャパシタ両端の実測電圧を測り、シリアルログの `V_store_mV` （実測値×2の計算）と整合しているか（誤差 ±0.1V 以内）確認。

### ステップ 3-3: 熱電発電と初期充電のテスト
1. TEG モジュールの高温側（手のひら接触面）を手でしっかりと暖めます。
2. シリアルログの `T_hot_C` が上昇し、`deltaT_C` が **10℃ 以上**（例: $T_{\text{hot}} = 34^\circ\text{C}, T_{\text{cold}} = 22^\circ\text{C}$）になることを確認します。
3. `V_store_mV` が徐々に上昇し、**3000 mV (3.0V) 以上** に達することを確認します。

## 6. Phase 4: USB抜去と完全自律駆動デモの実行

いよいよ、**「外部電源なし・体温のみで動き続ける悪魔」** の自律駆動デモを行います！

```
【自律移行のシーケンス】
 1. 体温でTEGを温め、V_store ≧ 3.0V まで蓄電
 2. シリアルログで Deep Sleep (10秒休眠) に入った瞬間を確認
 3. 🔌 USB-C ケーブルをすばやく抜去!
 4. BAT54 ダイオードORにより無瞬断で TEG+スーパーキャパシタ給電に移行
 5. 💡 10秒ごとに緑色LED (LED_demon) が鮮やかにパルス点灯!
```

### 実行ステップ:
1. 手のひらで TEG 高温部を保持し、$\Delta T \ge 10^\circ\text{C}$ を維持します。
2. シリアルモニタで `V_store` が **3.2V〜3.5V** 付近まで上昇したことを確認します。
3. **USB-C ケーブルを抜去**します。
4. **観察**:
   - PCとの接続を完全に切断しても、XIAO ESP32-C3 はリセットされることなく自律動作を継続します。
   - **10秒周期** で Deep Sleep から復帰し、**緑色 LED (LED_demon) がピカッとパルス発光 (100ms)** して再び Deep Sleep に戻るサイクルが永遠に繰り返されます。

> [!NOTE]
> **低電圧保護機能の動作用確認**
> 体温から手を離して放置し $V_{\text{store}} < 3.0\text{V}$ まで低下すると、コード内のブラウンアウト保護機能が働き、マイコンは 30 秒間のロングスリープ休眠に入り、再びエネルギーが蓄積されるのを待ちます。

## 8. Phase 6: トラブルシューティングガイド

不具合が発生した場合は、以下の診断ツリーに従って原因を特定・対処してください。

```
                                  [ トラブル診断フロー ]
                                             │
                       ┌─────────────────────┴─────────────────────┐
                       ▼                                           ▼
             【緑色LEDが光らない】                        【USB抜去時にリセットする】
                       │                                           │
         ┌─────────────┼─────────────┐               ┌─────────────┼─────────────┐
         ▼             ▼             ▼               ▼             ▼             ▼
   V_store < 2.5V   MOSFETピン逆   LED極性逆     BAT54向き逆   100μFコンデンサ抜  V_store不足
   (温め不足)       (G,D,S誤配線) (アノード/カソード)(D1/D2の極性) (VCC波形急降下) (3.0V未満で抜去)
         │             │             │               │             │             │
         ▼             ▼             ▼               ▼             ▼             ▼
   ΔT ≧ 10℃維持   印字面手前で   長足/短足を     帯マーク(カソ  VCC_nodeに100μF 3.3V以上確認後
   で蓄電を待つ   左から1,2,3    再確認          ード)をVCCへ  を追加配線      抜去する
```

### 詳細対照表

| 症例・エラー | 想定される原因 | 対策・確認手順 |
|:---|:---|:---|
| **DS18B20 が `-127.0℃` を返す** | OneWire 配線不良、または 4.7kΩ プルアップ抵抗の欠落 | Dataピン (GPIO2) と VCC_node の間に 4.7kΩ 抵抗が接続されているか確認。ブレッドボードの接触不良をチェック。 |
| **$V_{\text{store}}$ が全く上昇しない** | TEG の極性反転、または LTC3108 のジャンパ設定ミス | TEG の赤/黒線を入れ替えて試す。LTC3108 の `VS1` ピンが HIGH (3.3V) に固定されているか確認。 |
| **USBを抜いた瞬間にマイコンが停止する** | ダイオード BAT54 の向きが逆、または平滑コンデンサ不足 | D1/D2 のカソード（帯側）が `VCC_node` を向いているか確認。`VCC_node` に 100μF 電解コンデンサが接続されているか確認。 |
| **LEDが薄暗く常時点灯してしまう** | MOSFET のゲートが浮いている（Hi-Z 状態） | GPIO3 から GND への **10kΩ プルダウン抵抗** が抜けていないか確認。 |
| **緑色LEDがパルス発光しない** | MOSFET の型番違い (標準パワーMOSFETの使用) | `IRF540N` 等は 3.3V で駆動できません。ロジックレベル駆動型の `IRLZ44N` に変更してください。 |
