## はじめに
ようこそ！このマニュアルでは、電子工作が**初めての方**でも確実に組み立てられるように、「マクスウェルの悪魔」体温発電デモデバイスの作り方をステップバイステップで解説します。

**このデバイスがすること**
人間の「体温」と「室温」のわずかな温度差（たった10℃程度）から電気を作り出し、内蔵のスーパーキャパシタ（蓄電器）にエネルギーを貯めます。そして、スマートなマイコンがエネルギー残量を監視しながら、賢くエネルギーを使ってLEDを点滅させます。まるで、エネルギーを選別する「マクスウェルの悪魔」のような振る舞いを観察できます！

```
 ┌──────────────────────────────────────────────────┐
 │   🖐️ 体温 (36℃)                                  │
 │       ↓                                          │
 │   [ ペルチェ素子 ] ← 温度差で発電                 │
 │       ↓                                          │
 │   [ 昇圧モジュール ] ← 微弱な電圧を3.3Vに昇圧    │
 │       ↓                                          │
 │   [ スーパーキャパシタ ] ← エネルギーを蓄電       │
 │       ↓                                          │
 │   [ ESP32-C3 マイコン ] ← 「悪魔」が賢く判断     │
 │       ↓                                          │
 │   [ 💡 LED がパルス点灯! ] ← 仕事を抽出！       │
 └──────────────────────────────────────────────────┘
```

**ここで学べること**
- ブレッドボードを使った電子回路の組み立て
- 基本的な電子部品の役割と使い方（LED、抵抗、ダイオード、MOSFETなど）
- マイコン（ESP32-C3）のプログラミング基礎
- 超低電圧環境でのエネルギーマネジメント

> [!WARNING]
> **安全についてのお知らせ**  
> 本デバイスは5V以下の低電圧で動作するため、感電の危険性はなく安全です。ただし、部品の向き（極性）を間違えると部品が壊れることがあります。マニュアルの図をよく見て、極性をしっかり確認しながら進めましょう。

### 2. 超低電圧昇圧モジュール (LTC3108 - CJMCU-3108)
TEG（ペルティエ素子）からのわずかな電圧（0.02V程度）を、マイコンが動ける3.3Vに昇圧（電圧を上げる）する「心臓部」です。

### 3. ペルティエ素子 (TEG: SP1848-27145)
温度差を電気に変える魔法の板です。片面が熱く、もう片面が冷たいときに発電します。
赤線がプラス(+)、黒線がマイナス(-)です。

### 4. スーパーキャパシタ (1.0F 5.5V EDLC)
電気をたっぷり貯められる「巨大なバケツ」です。
💡 **極性:** 足が長い方がプラス(+)、短い方がマイナス(-)です。側面に「-」の帯があります。

### 5. 電解コンデンサ (100μF 16V)
電圧の変動を滑らかにする「クッション」です。
```text
  [+] 長い足
   |
  ( )
   |
  [-] 短い足 (側面に「-」の白い帯)
```
> [!CAUTION]
> 電解コンデンサは必ず極性を守ってください。逆に繋ぐと破裂する恐れがあります！

### 6. ショットキーバリアダイオード (1N5819 / BAT54 / BAT54CT)
電気を一方通行にする「逆流防止弁」です。電圧降下の少ないショットキータイプを使用します。

**【標準推奨】リード線付き 1N5819 を使用する場合**
```text
       (アノード:+)      (カソード:-)
      ------|>|------[銀色の帯]----
```
💡 **極性:** 本体にある**銀色（または白）の帯**が描かれている側がカソード（マイナス側 / 電気が流出する側）です。ハンダ付けなしでそのままブレッドボードに直挿しできます。耐圧40V・電流1Aのスペックですが、3.3V〜5Vの超低電力回路でも全く問題なく作動します。

> [!NOTE]
> **BAT54CT (SOT-23 表面実装品) をお持ちの場合**
> - **挿せない理由**: BAT54 / BAT54CT は超小型の表面実装部品（SOT-23パッケージ: ピン間隔0.95mm）のため、そのままではブレッドボード（穴間隔2.54mm）に挿せません。
> - **基板変換して使う方法**: 「SOT-23 変換基板（DIP化基板）」にハンダ付けし、2.54mmピンヘッダを立ててブレッドボードに挿します。
>   - ※ **BAT54CT** は内部で2基のダイオードのカソードが共通化（コモンカソード）されているため、**1個のモジュールで D1(USB電源) と D2(TEG電源) の両方のダイオードOR回路を兼ねることができます**（Pin1: USB 5V, Pin2: LTC3108 VOUT, Pin3: VCC_node）。

### 7. MOSFET (IRLZ44N)
小さな信号で大きな電気をスイッチングする「電子スイッチ」です。
```text
       ___
      |   | (背面の金属)
      |___|
      |   | IRLZ44N
      |___| (文字の書いてある面を正面にする)
      | | |
      | | |
     /  |  \
   Gate |  Source (右 / ピン3)
 (左/1) |
      Drain (中央 / ピン2)
```

### 8. LED (発光ダイオード) - 赤・緑
光る部品です。
```text
  [+] アノード (長い足)
   |
  ( )
   |
  [-] カソード (短い足 / 鍔が少し平ら)
```

### 9. 抵抗器 (100Ω, 220Ω, 330Ω, 4.7kΩ, 10kΩ)
電気の流れにくさを作る部品です。極性はありません。
カラーコード（しましま模様）で値が決まります（付録A参照）。

### 10. 温度センサー (DS18B20 防水プローブ)
温度を測るセンサーです。
💡 **配線色:** 赤=VCC(プラス), 黒=GND(マイナス), 黄色(または青)=データ線

## 第2章: ブレッドボードの基礎知識
はんだ付けなしで回路を作れる魔法のボードです。

```text
    (+)赤ライン ------------------------------------ (横に繋がっている)
    (-)青ライン ------------------------------------ (横に繋がっている)

  a [ o o o o o ]  [ o o o o o ]
  b [ o o o o o ]  [ o o o o o ]  縦の5つの穴が
  c [ o o o o o ]  [ o o o o o ]  内部で繋がっている
  d [ o o o o o ]  [ o o o o o ]
  e [ o o o o o ]  [ o o o o o ]
       (中央の溝)
  f [ o o o o o ]  [ o o o o o ]
  g [ o o o o o ]  [ o o o o o ]
  h [ o o o o o ]  [ o o o o o ]
  i [ o o o o o ]  [ o o o o o ]
  j [ o o o o o ]  [ o o o o o ]

    (+)赤ライン ------------------------------------ (横に繋がっている)
    (-)青ライン ------------------------------------ (横に繋がっている)
```
- 上下の赤・青ラインは「電源レール」です。横一列がすべて繋がっています。
- 中央のa~e、f~jの穴は、縦（列）の5個ずつが繋がっています。
- 中央の溝を挟んで上（a~e）と下（f~j）は繋がっていません。

## 第3章: 回路を組み立てよう

> [!IMPORTANT]
> 組み立て中は、絶対にマイコンをUSBに繋がないでください！

### Step 1: マイコン (ESP32-C3) を配置する
マイコンをブレッドボードの中央の溝をまたぐように挿し込みます。
```text
   +-------------------+
   |  [+] (上部赤ライン) | <-- 3V3ピンからジャンパワイヤで繋ぐ (これがVCC_nodeになります)
   |  [-] (上部青ライン) | <-- GNDピンからジャンパワイヤで繋ぐ
   +-------------------+
     a b c d e f g h i
   +-------------------+
  1| O O O O O | O O O | 5V
  2| O O O O O | O O O | GND  --> [上部青ラインへ]
  3| O O O O O | O O O | 3V3  --> [上部赤ラインへ]
  4| O O O O O | O O O | D10
    ...
```
✅ **確認:** マイコンがしっかり奥まで挿さっているか確認しましょう。

### Step 2: ダイオードOR電源回路を作る
USBからの電源と、TEGからの電源をスムーズに切り替えるための回路です（1N5819を2本使用）。

1. **D1 (1N5819 / BAT54):** アノード(帯がない側)をマイコンの「5V」ピンの列へ。カソード(銀色の帯がある側)を上部赤ライン(VCC_node)へ挿し込みます。
2. **D2 (1N5819 / BAT54):** カソード(銀色の帯がある側)を上部赤ライン(VCC_node)へ。アノード(帯がない側)は空いている列へ挿し込みます（後でLTC3108のVOUTに繋ぎます）。
3. **電解コンデンサ(100μF):** 長い足(+)を上部赤ラインへ。短い足(-)を上部青ライン(GND)へ。

```text
  XIAO 5V --->|--- (D1: 1N5819 銀帯) ---> 上部赤ライン(VCC_node)
  (LTC VOUT)->|--- (D2: 1N5819 銀帯) ---> 上部赤ライン(VCC_node)
```
※ SOT-23変換基板に実装した **BAT54CT** をお使いの場合は、モジュールの Pin1(Anode 1) を XIAO 5V、Pin2(Anode 2) を LTC3108 VOUT、Pin3(Common Cathode) を上部赤ライン(VCC_node) に繋ぐことで、D1・D2 を1個で兼ねることができます。

✅ **確認:** ダイオードの銀色の帯の向き、コンデンサの白い帯(-)の向きを間違えていないか再確認！

### Step 3: 昇圧モジュールとスーパーキャパシタを接続する
1. **TEG:** 赤線をLTC3108の「VIN+」へ。黒線を「GND」へ。
2. **LTC3108のVS1ピン:** 「HIGH (または VOUT)」に繋いで、出力を3.3Vに設定します。
3. **LTC3108のVOUT:** Step2で作ったD2のアノードに繋ぎます。
4. **スーパーキャパシタ (1.0F):** 長い足(+)をLTC3108の「VSTORE」へ。短い足(-)を青ライン(GND)へ。

✅ **確認:** スーパーキャパシタの極性が正しいか確認！

### Step 4: MOSFET スイッチ回路を作る
エネルギーを無駄遣いしないためのスイッチを作ります。IRLZ44Nを文字面を正面にして挿します。

1. **Gate (左/1ピン):** ジャンパワイヤでマイコンの「左側2番目: A1/D1 (GPIO3)」へ（間に220Ω抵抗を挟む）。
2. **Gate (左/1ピン) と GND:** 10kΩ抵抗を繋ぎます（プルダウン抵抗）。
3. **Source (右/3ピン):** 青ライン(GND)へ繋ぎます。

```text
  [左側2番目: A1/D1 (GPIO3)] ---[ 220Ω ]---+---> Gate (左ピン)
                                            |
                                         [ 10kΩ ]
                                            |
                                          [GND]
```
✅ **確認:** MOSFETの表裏が間違っていないか、各ピンが隣同士でショートしていないか確認。

### Step 5: LED回路を作る
**悪魔LED (緑):** 発電した電気で光ります。
1. VSTORE（スーパーキャパシタの+）から100Ω抵抗を繋ぐ。
2. 100Ωの先を、緑LEDの長い足（アノード）へ。
3. 緑LEDの短い足（カソード）を、MOSFETの中央ピン（Drain）へ。

**パッシブLED (赤):** マイコンの状態で光ります。
1. マイコンの「左側4番目: A3/D3 (GPIO5)」から赤LEDの長い足（アノード）へ。
2. 赤LEDの短い足（カソード）から330Ω抵抗を繋ぐ。
3. 330Ωの先を青ライン(GND)へ。

✅ **確認:** LEDの長い足と短い足の向きを確認！

### Step 6: 電圧モニタ (分圧回路) を作る
マイコンは3.3Vまでしか測れないので、電圧を半分にして測ります。

**VSTORE用:**
1. VSTORE から 10kΩ抵抗を挿し、その先をマイコンの「左側3番目: A2/D2 (GPIO4)」へ。
2. マイコンの「左側3番目: A2/D2 (GPIO4)」から 10kΩ抵抗を挿し、その先を青ライン(GND)へ。

**VOUT用:**
1. LTC3108のVOUT から 10kΩ抵抗を挿し、その先をマイコンの「左側5番目: SDA/D4 (GPIO6)」へ。
2. マイコンの「左側5番目: SDA/D4 (GPIO6)」から 10kΩ抵抗を挿し、その先を青ライン(GND)へ。

```text
  VSTORE --->[ 10kΩ ]---+---> [左側3番目: A2/D2 (GPIO4)]
                        |
                     [ 10kΩ ]
                        |
                      [GND]
```
✅ **確認:** 抵抗の値が10kΩであることをカラーコードで確認。

### Step 7: 温度センサーを接続する
2つのDS18B20センサーを並列に繋ぎます。

1. **赤線(VCC):** 2本とも上部赤ライン(VCC_node / 3.3V)へ。
2. **黒線(GND):** 2本とも上部青ライン(GND)へ。
3. **黄/青線(データ):** 2本ともマイコンの「左側一番上: A0/D0 (GPIO2)」へ。
4. **プルアップ抵抗:** マイコンの「左側一番上: A0/D0 (GPIO2)」と上部赤ライン(VCC_node)の間に、4.7kΩ抵抗を繋ぎます（またがせて接続）。

- **220Ω:** 赤・赤・茶・金
- **330Ω:** 橙・橙・茶・金
- **4.7kΩ:** 黄・紫・赤・金
- **10kΩ:** 茶・黒・橙・金

## 付録B: 用語集
- **ブレッドボード:** はんだ付けなしで部品を挿すだけで回路が作れる実験ボード。
- **GPIO:** マイコンのピン。電気を出力したり、入力として読み取ったりできる。
- **ADC:** アナログ・デジタル変換。電圧の大きさを数値として読み取る機能。
- **MOSFET:** 電圧でオン・オフを切り替えることができる強力な電子スイッチ。
- **ショットキーダイオード (1N5819 / BAT54):** 電気が逆流するのを防ぐ部品。普通のダイオードより電圧のロスが少ない（スルーホール型の1N5819はブレッドボード直挿しが可能）。
- **OneWire:** 1本のデータ線だけで複数のセンサーと通信できる仕組み。
- **Deep Sleep:** マイコンの超省電力モード。寝ている間はほとんど電気を使わない。
- **プルアップ/プルダウン抵抗:** 信号の電圧がフワフワ不安定になるのを防ぐため、VCCやGNDに繋いでおく抵抗。
- **ダイオードOR回路:** 2つの電源（USB と TEG発電）のうち、電圧が高い方を自動的にマイコンに供給する回路。USBを抜いても途切れずに電源が切り替わります。
- **スーパーキャパシタ:** 非常に大容量のコンデンサ。電気を大量に蓄えることができ、短時間で充放電が可能です。
- **ゼーベック効果:** 温度差があると電圧が発生する物理現象。ペルチェ素子（TEG）がこの効果を利用して発電します。
- **ランダウアー限界:** 情報を消去するために必要な最小エネルギー。このデバイスは、悪魔のコストがこの限界を下回ることを実証します。
