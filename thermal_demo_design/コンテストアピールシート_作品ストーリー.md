**応募分類**: 発明工夫コンテスト / 自由研究・科学展（小・中・高校生・一般の部対応）  
**作品名**: **『手ぶくろ要らず！体温と熱源で光る 電池ゼロのSOS防災ライト』**  
**作品サブタイトル**: 〜 マクスウェルの悪魔（熱情報量子科学）が拓く、電池不要の自律型環境給電システム 〜

## 1. 作品コンセプト・キャッチコピー

> **「乾電池も、充電も、コンセントもいらない。必要なのは、あなたの体温（僅か0.5℃の温度差）だけ。」**
>
> 災害時、冬場の暗い避難所で電池が切れても大丈夫。  
> プレートを両手でギュッと握る（または温かいペットボトルを乗せる）だけで、体温と外気温のわずかな温度差から電気を生み出し、マイコン（マクスウェルの悪魔）が自律的に赤色LEDで「SOS（・・・ ─── ・・・）」の救援信号を発光し続ける、電池ゼロのレスキューライトです。

---

## 2. 開発背景と解決する課題（ストーリー）

1. **背景**: 災害や大停電が発生した際、非常用ライトや懐中電灯は「乾電池の買い置き忘れ」や「液漏れ・長期放置による電池切れ」によって、いざという時に使えないトラブルが頻発します。
2. **着眼点**: 人間は生きている限り、常に「体温（熱エネルギー）」を放出しています。冬場の避難所の冷たい空気や机との間には、**「温度差 $| \Delta T |$」**が存在します。
3. **課題**: 体温から得られる電気はほんのわずか（超低電圧・微小電力）で、そのまま連続点灯させようとすると一瞬で電気が底をついてしまいます。
4. **解決策**: 最先端の物理概念である**「マクスウェルの悪魔（熱情報量子科学）」**を応用！マイコンの Deep Sleep（超省エネ待機: 5μA）とベイズ推定フィードバック制御を組み合わせ、「無駄な電気を使わず、赤色LEDのSOS情報として高効率にパルス発光させる」ことで、乾電池ゼロでの完全自律動作に成功しました。

## 3. 作品の3大発明ポイント（ここがすごい！）

### 🌟 ポイント①：【僅か0.5℃の温度差で自律発動！】6枚直列プレート ＆ 高速熱センシング
* 単枚の熱電素子（TEG）ではなく、**6枚のTEGを2×3（約8cm×12cm）に配列・直列接続**。
* 手のひら両手分、または「温かいペットボトル・缶コーヒー」を乗せられる広い受熱面積を確保。
* DS18B20温度センサーの9-bit高速計測（93ms）と絶対値演算 `fabs()` により、**僅か0.5℃の微小温度差を逃さず検知**して自律起動します。

### 🌟 ポイント②：【視認性抜群！2色LEDによる状態の可視化】
* 🟡 **黄色LED（動作インジケーター）**: マイコンが体温で自律起床し、温度・電圧を計測した瞬間に15msだけ短くピカッと点滅（「体温でマイコンが動いた！」という感動を可視化）。
* 🔴 **赤色LED（SOS発光ライト）**: 非常用のハイパワー赤色LEDで「SOS（・・・ ─── ・・・）」のモールス符号を発光。

### 🌟 ポイント③：【熱情報量子科学の実証】ランドウアー限界の可視化 ＆ 環境適応発光
* マイコン内部で情報処理コスト（ランドウアーの消去熱 $W_{\text{erase}} = k_B T \ln 2$）と抽出エネルギー（$W_{\text{ext}}$）を計算し、シリアルログにリアルタイム出力。
* 熱エネルギーが潤沢な時は**12秒〜25秒に1回のハイペースSOS発光**、微小温度差時は**エコ短縮パルス（45秒〜60秒）**へと自律的にピッチとパルス幅を調整します。

## 4. 審査員を惹きつける「キラーアピールフレーズ集」

審査員（理科教員・専門家）からの質問に対する、印象抜群のキラー回答フレーズです。

| 予想される質問 | 審査員を唸らせるキラーフレーズ・回答 |
| :--- | :--- |
| **Q1. 「体温だけで本当にマイコンやLEDが動くの？」** | **「はい！黄色LEDが一瞬ピカッと光るのが体温でマイコンが自律起床した証拠です。マイコンは99.9%の時間を Deep Sleep（5μA）で眠らせ、僅か0.5℃の体温差が溜まった瞬間だけ赤色LEDで『SOSモールス信号』を発光させています。」** |
| **Q2. 「なぜ連続点灯ではなくモールス信号（SOS）なの？」** | **「ダラダラ点灯させると一瞬で電気が底をつきますが、『SOS』という情報の形にしてパルス点滅させることで、エネルギー消費を抑え、体温だけで長時間救助を呼び続けられるからです！」** |
| **Q3. 「回路にあるUSB端子は何のためにあるの？」** | **「二重化（ハイブリッド）安全設計です。設置時はUSBで充電し、災害時にUSBが抜けても一瞬の停電もなく無瞬断で『体温自律発電』に自動切り替え（ダイオードOR回路）できます。」** |
| **Q4. 「マクスウェルの悪魔（熱情報量子科学）って何関係があるの？」** | **「悪魔が温度を見張って『今だ！』という時だけゲート（MOSFET）を開いて仕事を取り出すという、物理学の情報エンジン（ランドウアー限界の超越）を電子回路で再現しています！」** |
