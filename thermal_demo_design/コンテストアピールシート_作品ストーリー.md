# コンテスト発表用 アピールシート ＆ 作品ストーリー

**応募分類**: 発明工夫コンテスト / 自由研究・科学展（小・中・高校生の部対応）  
**作品名**: **『手ぶくろ要らず！体温と熱源で光る 電池ゼロのSOS防災ライト』**  
**作品サブタイトル**: 〜 マクスウェルの悪魔（情報理論）が拓く、電池不要の非常用環境給電システム 〜  

---

## 1. 作品コンセプト・キャッチコピー

> **「乾電池も、充電も、コンセントもいらない。必要なのは、あなたの体温だけ。」**
>
> 災害時、冬場の暗い避難所で電池が切れても大丈夫。  
> プレートを両手でギュッと握る（または温かいペットボトルを乗せる）だけで、体温と外気温の温度差から電気を生み出し、自律的に赤色LEDで「SOS（・・・ ─── ・・・）」の救援信号を発光し続ける、電池ゼロのレスキューライトです。

---

## 2. 開発背景と解決する課題（ストーリー）

1. **背景**: 災害や大停電が発生した際、非常用ライトや懐中電灯は「乾電池の買い置き忘れ」や「液漏れ・電池切れ」によって、いざという時に使えないトラブルが頻発します。
2. **着眼点**: 人間は生きている限り、常に「約36℃の体温（熱エネルギー）」を放出しています。冬場の避難所の冷たい床や空気（10〜15℃）との間には、**「大きな温度差 $\Delta T$」**が存在します。
3. **課題**: 体温から得られる電気はほんのわずか（超低電圧・微小電力）で、そのままではマイコンやライトを動かす前に一瞬で電気を使い果たしてしまいます。
4. **解決策**: 最先端の物理概念である**「マクスウェルの悪魔（情報エンジン）」**を応用！マイコンのDeep Sleep（超省エネ待機）と温度監視を組み合わせ、「無駄な電気を使わず、赤色LEDのSOS情報として効率よくパルス発光させる」ことで、電池なしでの自律動作に成功しました。

---

## 3. 作品の3大発明ポイント（ここがすごい！）

### 🌟 ポイント①：【両手で包める 6枚直列プレート】で体温を余さず回収
* 単枚の熱電素子（TEG）ではなく、**6枚のTEGを2×3（約8cm×12cm）に配列・直列接続**。
* 手のひら両手分、または「温かいペットボトル・缶コーヒー」をドカッと乗せられる広い面積を確保。
* わずか数度の温度差から**0.9V以上の起電力**を叩き出し、超低電圧昇圧回路を安定駆動させます。

### 🌟 ポイント②：【視認性抜群！2色LEDによる状態の可視化】
* 🟡 **黄色LED（動作インジケーター）**: マイコンが体温で自律起床し、温度・電圧を計測した瞬間に短くピカッと点滅。
* 🔴 **赤色LED（SOS発光ライト）**: 非常用の赤色LEDで「SOS（・・・ ─── ・・・）」のモールス符号を発光。

### 🌟 ポイント③：【環境適応型】温度差に合わせてSOSのピッチが自動変化
* 温度センサーが体温の強さ（温度差 $\Delta T$）をリアルタイムで測定。
* 手が温かくエネルギーが潤沢な時は**10秒に1回のハイペース発光**、手が冷えている時は**20秒〜30秒に1回のエコ発光**へと自律的にピッチを調整します。

## 4. 審査員を惹きつける「キラーアピールフレーズ集」

審査員（理科教員・専門家）からの質問に対する、印象抜群のキラー回答フレーズです。

| 予想される質問 | 審査員を唸らせるキラーフレーズ・回答 |
| :--- | :--- |
| **Q1. 「体温だけで本当にマイコンやLEDが動くの？」** | **「はい！黄色LEDが一瞬ピカッと光ったのがマイコンが自律起床した証拠です。マイコンは普段99.9%の時間を『Deep Sleep（5μA）』で眠らせ、体温が溜まった瞬間だけ赤色LEDで『SOSモールス信号』を発光させています。」** |
| **Q2. 「なぜ連続点灯ではなくモールス信号（SOS）なの？」** | **「ダラダラ点灯させると数秒で電気が底をつきますが、『SOS』という情報の形にしてパルス点滅させることで、エネルギー消費を1/10以下に抑え、手持ちの体温だけで長時間救助を呼び続けられるからです！」** |
| **Q3. 「回路にあるUSB端子は何のためにあるの？」** | **「二重化（ハイブリッド）安全設計です。普段や設置時はUSBで一瞬で事前充電し、災害時にUSBが抜けても一瞬の停電もなく無瞬断で『体温自律発電』に自動切り替え（ダイオードOR回路）できます。」** |
| **Q4. 「マクスウェルの悪魔って何関係があるの？」** | **「悪魔が温度を見張って『今だ！』という時だけゲート（MOSFET）を開いて仕事を取り出すという、物理学の情報エンジン（ランダウアー限界の超越）を電子回路で再現しています！」** |
