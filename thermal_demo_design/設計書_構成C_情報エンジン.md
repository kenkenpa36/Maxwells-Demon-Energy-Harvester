## 設計コンセプト

### 何を検証するか

体温と外気温の**微小温度差（ΔT≈5〜15℃）**という極めて厳しい条件下で、「情報によるフィードバック制御（マクスウェルの悪魔）」がエネルギー抽出効率をどう変えるかを体験する。

```
┌─────────────────────────────────────────────────────────┐
│                   実験の3つの発見                        │
│                                                         │
│  ① 悪魔（Arduino）があるとLEDがより明るく光る           │
│     → 情報フィードバックは仕事抽出を改善する            │
│                                                         │
│  ② しかし悪魔自身の消費電力(150mW) ≫ 改善分(〜8mW)     │
│     → 古典的ランダウアー限界: 情報処理コスト > 利得     │
│                                                         │
│  ③ 論文の提案: 量子もつれなら消去コストが負に反転       │
│     → この実験の「コスト負け」が逆転する               │
└─────────────────────────────────────────────────────────┘
```

### 2つのパスの比較

| | Path A: Feedback OFF | Path B: Feedback ON |
|:---:|:---:|:---:|
| 制御 | なし（受動的） | Arduino（悪魔） |
| LED接続 | VOUT直結、常時 | MOSFET経由、最適タイミング |
| LED動作 | **暗い / 消灯**（電圧不足） | **明るくパルス点灯** |
| 論文対応 | 第II章: 基本エンジン | 第IV章: ベイズ推定制御 |

## 回路図

![構成C回路図](file:///home/imaken/notebook_project/Maxwells_demon/thermal_demo_design/circuit_diagram_C.svg)

### 配線表

| Arduino ピン | 接続先 | 用途 |
|:---:|:---:|:---:|
| **D2** | DS18B20 DATA (2本共通) + 4.7kΩプルアップ | 温度測定 (OneWire) |
| **D3** | MOSFET (IRLZ44N) Gate → 220Ω | 悪魔のゲート制御 |
| **D5** | 330Ω → LED_passive (赤) → GND | 比較用LED (常時接続) |
| **A0** | 10kΩ分圧 ← VSTORE | キャパシタ電圧モニタ |
| **A1** | 10kΩ分圧 ← VOUT | 出力電圧モニタ |
| **5V** | DS18B20 VCC | センサー電源 |
| **GND** | 全体GND | 共通グランド |
| **USB** | PC接続 | Arduino電源 + データ記録 |

### MOSFET周りの配線詳細

```
CJMCU-3108 VOUT ──→ MOSFET Drain
                        │
Arduino D3 ─ 220Ω ──→ MOSFET Gate
                        │
                    MOSFET Source ──→ 100Ω ──→ LED_demon (緑) ──→ GND
```

### 電圧分圧回路（A0, A1）

```
VSTORE (max 5.5V) ──→ 10kΩ ──┬──→ Arduino A0
                              │
                            10kΩ
                              │
                             GND

読取電圧 = A0 × 2  (分圧比 1:1)
```

## 組み立て手順

### Step 1: ブレッドボード配線

1. Arduino Nano をブレッドボード中央に挿す
2. CJMCU-3108 モジュールを隣に配置
3. 配線表に従って接続

### Step 2: TEGの熱スタック

```
      ┌─────────────────┐
      │  ヒートシンク     │ ← 外気に露出（低温側）
      ├─────────────────┤
      │  熱伝導グリス     │
      ├─────────────────┤
      │  SP1848-27145    │ ← TEGモジュール
      ├─────────────────┤
      │  熱伝導グリス     │
      └─────────────────┘
            ↑
        手のひらで握る（体温面）
```

### Step 3: ソフトウェア

1. Arduino IDE をインストール
2. ライブラリマネージャから `OneWire` と `DallasTemperature` をインストール
3. [maxwell_demon_harvester.ino](file:///home/imaken/notebook_project/Maxwells_demon/thermal_demo_design/maxwell_demon_harvester.ino) をArduinoに書き込み
4. シリアルモニターを 9600bps で開く

### Step 4: 実験開始

1. TEGを手で握る（体温面を下側に）
2. ヒートシンク側は外気に露出
3. シリアルモニターでリアルタイムデータを確認
4. 30秒ごとにFeedback OFF/ONが切り替わる
