## 1. 全体概要・作品コンセプト

### 1-1. 作品名
**『手ぶくろ要らず！体温と熱源で光る 電池ゼロのSOS防災ライト』**

### 1-2. コンセプトと解決する課題
* **課題**: 災害時や大停電時、非常用ライトの電池が切れていると使えない。冬場の避難所では手足がかじかみ、暗闇の中で救援を呼ぶ手段が限られる。
* **解決策**: 乾電池・バッテリー一切不要！人間の**「手のひらの体温（僅か0.5℃の温度差）」**や**「温かい缶・ペットボトル」**をプレートに乗せるだけで、熱電発電（ゼーベック効果）と超低消費電力マイコン（ESP32-C3）の Deep Sleep 自律フィードバック制御により、自律的に赤色LEDでSOS信号（モールス符号パルス）を発光し続ける緊急レスキューライト。

### 2-2. 接着・固定方法（メカニカルアセンブリ）

> [!IMPORTANT]
> シリコングリスは「熱伝導用」であり接着力がありません。必ず以下のいずれかの方法で**物理的に圧着（締め付け固定）**します。

* **推奨方法 A: 「中央シリコングリス ＋ 四隅ボルト締め / アクリル圧着」**
  * TEG接触面の中央にシリコングリスを薄く塗り、四隅をボルトナットで締め付けます（熱伝導率最大）。
* **推奨方法 B: 「熱伝導両面テープ ＋ カプトンテープ / 結束バンド補強」**
  * 熱伝導両面テープで貼り付け、外周をカプトンテープ（耐熱テープ）または結束バンドでしっかり圧着します。

## 3. 温度センサー（DS18B20 × 2本）の配置 ＆ 高速化設計

温度センサー2本（OneWire経由）でリアルタイムに温度差 $\Delta T = |T_{hot} - T_{cold}|$ を監視します。

```text
                               [表面アルミ板]
                          ┌────────────────────┐
                          │  🌡️ DS18B20 (Thot)  │ ← ① 高温側センサー: 表面アルミ板の裏面に固定
                          └────────────────────┘
                                 ［ TEG ］
                          ┌────────────────────┐
                          │  🌡️ DS18B20 (Tcold) │ ← ② 低温側センサー: 裏面ヒートシンクのフィン間に固定
                          └────────────────────┘
                               [ヒートシンク]
```

### 3-1. 9-bit 高速測定 ＆ 絶対値演算（`fabs`）アルゴリズム
1. **9-bit 高速測定**: 解像度を9-bitに設定し、温度変換時間を **750ms ➔ 93.75ms** へ短縮。起床時間を1/8に削減し、悪魔自身の電力消費を劇的に削減。
2. **絶対値演算 `fabs(T_hot - T_cold)`**: DS18B20の固有ID順序（OneWireアドレス）に依存せず、表裏どちらが温かくても **正確な温度差 $| \Delta T |$** を正しく検出。

## 5. 回路 ＆ 二重化電源（ダイオードOR ＆ 2色LED仕様）

### 5-1. 回路システムブロック図

```text
  [ TEG 6枚直列 ] (0.9V〜2.4V)
        │
        ▼
  [ 0.9V DC-DC USB昇圧 ] ──(5V出力)──┐
                                     ▼
  [ USB 5V 電源 (給電/充電用) ] ───► [ Diode-OR 切替回路 ] ──► [ 1.0F スーパーキャパシタ ]
                                      (BAT54 / 1N5819)              (蓄電プール)
                                             │
                                             ├────────────────┐
                                             ▼                ▼
                                     [ XIAO ESP32-C3 ]   [ MOSFET スイッチ ]
                                    (Deep Sleep 5μA)          │
                                             │                ▼
                                  🟡 黄色LED  │         🔴 赤色LED
                         (動作確認インジケーター)       (緊急SOS発光ライト)
```

### 5-2. 2色LED配色の仕様
* 🟡 **黄色LED (GPIO5直結 / 330Ω経由)**: マイコンが体温で自律起床・計測した瞬間に15msだけ短くピカッと点滅（自律動作インジケーター）。
* 🔴 **赤色LED (MOSFET/GPIO3駆動 / 100Ω経由)**: 緊急救援用「SOS」モールス信号発光ライト（ハイパワーパルス点滅）。

## 6. ソフトウェア・熱情報量子科学アルゴリズム（マクスウェルの悪魔制御）

### 6-1. 悪魔のベイズ推定 ＆ フィードバック制御フロー

```text
  【 Deep Sleep 待機状態 (消費電力 5μA) 】
               │
               ▼  (一定周期で復帰: 🟡黄色LEDが15msピカッ)
  【 温度差 |ΔT| (Thot - Tcold) および Vstore 電圧を測定 】
               │
       ┌───────┴────────────────────────────────┐
       ▼                                        ▼
  【 |ΔT| < 0.5℃ または Vstore < 2.4V 】   【 |ΔT| ≥ 0.5℃ かつ Vstore ≥ 2.4V 】
  (充電優先状態: CHARGING)                  (悪魔発動状態: DEMON_ACT)
       │                                        │
       ▼                                        ▼
  何もせず即座に Deep Sleep へ戻る           MOSFET ゲートを開き、
  (充電優先 45〜60秒スリープ)                🔴 赤色LEDで「SOS」モールス信号
                                            (・・・ ─── ・・・) をパルス点滅！
                                                │
                                                ▼
                                            Deep Sleep へ戻る (12〜25秒スリープ)
```

### 6-2. 熱情報量子科学 シリアルCSVログ仕様
シリアル出力（115200bps）で、物理量および量子ランドウアー消去コストをリアルタイム出力します：

```csv
cycle,T_hot_C,T_cold_C,deltaT_C,V_store_mV,demon_state,W_ext_mJ,W_landauer_mJ,W_net_mJ,next_sleep_s
1,27.0,28.0,1.0,5060,DEMON_ACT,2.45,0.74,1.71,25
```

- **`demon_state`**: `DEMON_ACT`（悪魔がフィードバック動作してSOS点灯） / `CHARGING`（充電中）
- **`W_ext_mJ`**: 抽出した電気仕事 $W_{\text{ext}} = \frac{1}{2} C (V_{\text{before}}^2 - V_{\text{after}}^2)$
- **`W_landauer_mJ`**: 古典情報消去コスト $W_{\text{erase}} = k_B T \ln 2 \cdot N$
- **`W_net_mJ`**: 正味仕事 $W_{\text{net}} = W_{\text{ext}} - W_{\text{landauer}}$（古典限界と量子反転の比較指標）
