## 1. 全体概要・作品コンセプト

### 1-1. 作品名（提案）
**『手ぶくろ要らず！体温と熱源で光る 電池ゼロのSOS防災ライト』**  
（英名: Self-Powered Thermal SOS Light with Maxwell's Demon Logic）

### 1-2. コンセプトと解決する課題
* **課題**: 災害時や停電時、非常用ライトの電池が切れていると使えない。冬場の避難所では手足がかじかみ、暗闇の中で救援を呼ぶ手段が限られる。
* **解決策**: 乾電池・バッテリー一切不要！人間の**「手のひらの体温」**や**「温かい缶・ペットボトル」**をプレートに乗せるだけで、熱電発電（ゼーベック効果）と超低消費電力マイコン（ESP32-C3）のDeep Sleep制御により、自律的にSOS信号（モールス符号パルス）を発光し続ける緊急レスキューライト。

### 2-2. 接着・固定方法（メカニカルアセンブリ）

> [!IMPORTANT]
> **シリコングリスだけでは接着できません！**  
> シリコングリスは「熱を伝えるための塗料」であり、接着力がありません。必ず以下のいずれかの方法で**物理的に圧着（強く挟み込み固定）**してください。

#### 固定方法の選定（以下のいずれかを実施）

* **推奨方法 A: 「中央シリコングリス ＋ 四隅をネジ止め / 外枠圧着」**
  * TEGの上下接触面の中央にシリコングリスを薄く均一に塗ります。
  * アルミ板とヒートシンクの四隅（または外枠）をボルト＆ナット、または透明アクリル板のフレームでサンドイッチしてギューッと締め付けます。
  * **メリット**: 最も密着度が高くなり、熱伝導効率・発電量が最大になります。

* **推奨方法 B: 「熱伝導両面テープ ＋ 結束バンド / 耐熱テープ」**
  * TEGの両面に「熱伝導両面テープ」（Amazonや秋月電子で購入可能）を貼り、アルミ板とヒートシンクを接着します。
  * 外周を結束バンド（インシュロック）やカプトンテープ（耐熱テープ）でしっかり巻いて補強します。
  * **メリット**: ハンダ付けやネジ穴開けが不要で、工作が最も簡単です。

## 3. 温度センサー（DS18B20 × 2本）の配置設計

温度センサー2本は現状の回路・構成のまま使用します。リアルタイムで温度差 $\Delta T = T_{hot} - T_{cold}$ を監視するために必須です。

```text
                              [表面アルミ板]
                         ┌────────────────────┐
                         │  🌡️ DS18B20 (Thot)  │ ← ① 高温側センサー: 表面アルミ板の裏面または側面に固定
                         └────────────────────┘
                                ［ TEG ］
                         ┌────────────────────┐
                         │  🌡️ DS18B20 (Tcold) │ ← ② 低温側センサー: 裏面ヒートシンクのフィン間に挿入・固定
                         └────────────────────┘
                              [ヒートシンク]
```

### センサーの固定方法
* **$T_{hot}$（高温側センサー）**: 表面アルミ板の裏面（TEGの隙間）に熱伝導グリスを塗り、カプトンテープやアルミテープでしっかり密着・固定します。
* **$T_{cold}$（低温側センサー）**: ヒートシンクの放熱フィン（溝）の間に挿入し、熱伝導グリス＋テープで固定します。

## 5. 全体回路 ＆ 電源仕様（ハイブリッド二重化電源）

### 5-1. 回路システムブロック図

```text
  [ TEG 6枚直列 ] (0.9V〜2.4V)
        │
        ▼
  [ 0.9V DC-DC USB昇圧 ] ──(5V出力)──┐
                                     ▼
  [ USB 5V 電源 (給電/充電用) ] ───► [ Diode-OR 切替回路 ] ──► [ 1.0F スーパーキャパシタ ]
                                      (BAT54 / 1N5819)              (蓄電プール)
                                             │
                                             ├────────────────┐
                                             ▼                ▼
                                     [ XIAO ESP32-C3 ]   [ MOSFET スイッチ ]
                                    (Deep Sleep 5μA)          │
                                             │                ▼
                                             └─────────► [ 緑色 SOS LED ]
```

### 5-2. 回路の特徴（コンテストでの二重化電源アピール）
* **無瞬断電源切り替え（Diode-OR）**:
  * USBを接続している時は、USB 5Vからキャパシタへ超高速充電＆マイコン動作。
  * **USBを抜去した瞬間、一瞬の停電もなく無瞬断でTEG自律発電に自動切換**。
  * この二重化回路により、展示本番では「完全コードレス」でデモを行い、設営時やテスト時は「USBで一瞬で事前充電」することが可能です。

## 6. ソフトウェア・アルゴリズム仕様（マクスウェルの悪魔制御）

マイコン（`maxwell_demon_harvester_esp32c3.ino`）は変更不要でそのまま動作します。

```text
  【 Deep Sleep 待機状態 (消費電力 5μA) 】
               │
               ▼  (一定周期で復帰)
  【 温度差 ΔT (Thot - Tcold) および Vstore 電圧を測定 】
               │
       ┌───────┴────────────────────────┐
       ▼                                ▼
  【 ΔT < 閾値 (温度差不足) 】       【 ΔT ≥ 閾値 & Vstore 十分 】
       │                                │
       ▼                                ▼
  何もせず即座に                    MOSFET ゲートを開き、
  Deep Sleep へ戻る                 緑色LEDで「SOS」モールス信号
  (無駄なエネルギーを使わない)      (・・・ ─── ・・・) をパルス点滅！
                                        │
                                        ▼
                                    Deep Sleep へ戻る
```

## 7. コンテスト展示・デモ手順ガイド

### 7-1. 展示ブースでの配置
1. **作品本体**: 透明なアクリルケースやコレクションケースにブレッドボードを格納。
2. **プレート部**: サンドイッチ構造にした「2×3 TEGプレート」をケースの外に配置。
3. **パネル展示**: 
   * 「電池が入っていないこと」を強調する構成図。
   * 「ただ発電するだけでなく、マクスウェルの悪魔（Deep Sleep制御）で無駄な電気を使わないから長く光る」というロジックの説明イラスト。

### 7-2. 実演デモの手順（審査員が来た時）

1. **「どこにも電池もUSBケーブルも繋がっていません」** とコードレス状態を見せる。
2. 審査員に**「このアルミプレートを両手でギュッと挟んでみてください」**（または温かいペットボトルを乗せる）と促す。
3. 数秒〜十数秒後、キャパシタに十分な充電が溜まると、**緑色LEDが「ピ・ピ・ピ・ピー・ピー・ピー・ピ・ピ・ピ（SOS）」と点滅開始**。
4. 「体温だけでSOS信号が発光しました！」と説明し、会場を驚かせる。
