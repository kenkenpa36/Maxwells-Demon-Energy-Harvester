> **ファームウェア（プログラム）の変更は一切不要です。**

## 1. 仕組みの違い

### 元の構成（CJMCU-3108 / LTC3108）

```text
TEG 1枚 (20〜50mV) ──→ [LTC3108 昇圧IC] ──→ 3.3V出力 ──→ スーパーキャパシタ蓄電
                        (20mVから昇圧可能な
                         特殊な超低電圧昇圧IC)
```

### 今回の代替構成（TEG直列 ＋ USB昇圧モジュール）

```text
TEG 6枚直列 (0.9V〜3V) ──→ [USB DC-DC昇圧] ──→ 5V固定出力 ──→ スーパーキャパシタ蓄電
                             (0.9V以上で起動する
                              USB給電用の昇圧モジュール)
```

#### なぜ 6枚直列にするのか？

ペルチェ素子（TEG）1枚が生み出す電圧は、温度差10℃のとき約 **150mV〜200mV** です。
汎用昇圧モジュールは **0.9V 以上** ないと起動しません。

| TEG枚数 | 温度差10℃での発電電圧 | 温度差20℃での発電電圧 | 汎用昇圧モジュール |
| :---: | :---: | :---: | :---: |
| 1枚 | 約 0.15V〜0.2V | 約 0.3V〜0.4V | ❌ 起動不可 |
| 2枚 | 約 0.3V〜0.4V | 約 0.6V〜0.8V | ❌ ギリギリ不足 |
| 4枚 | 約 0.6V〜0.8V | 約 1.2V〜1.6V | ⚠️ 温度差大なら可 |
| **6枚** | **約 0.9V〜1.2V** | **約 1.8V〜2.4V** | **✅ 安定起動！** |

6枚直列にすることで、温度差10℃でも **0.9V〜1.2V** の電圧が得られ、汎用昇圧モジュールが安定して起動します！

## 3. TEG 6枚の直列接続

### 3-1. 直列接続とは？

乾電池を並べて繋ぐのと同じ原理です。
1個1.5Vの乾電池を2本直列にすると3Vになるように、
TEGも直列に繋ぐと **電圧が足し算** されます。

```text
     ┌──── TEG1 ────┐   ┌──── TEG2 ────┐         ┌──── TEG6 ────┐
     │  赤(+) 黒(-) │   │  赤(+) 黒(-) │  ・・・  │  赤(+) 黒(-) │
     └───┬──────┬───┘   └───┬──────┬───┘         └───┬──────┬───┘
         │      └───────────┘      └── ・・・ ──────┘      │
         │    （黒と赤を繋ぐ）    （黒と赤を繋ぐ）          │
         │                                                  │
    ここが全体の           ここが全体の
     プラス(+)              マイナス(-)
    昇圧モジュール          昇圧モジュール
     VIN+ へ                 GND へ
```

### 3-2. 具体的な繋ぎ方（6枚の場合）

> [!CAUTION]
> **すべてのTEGの「温める面」と「冷やす面」の向きを統一してください！**
> 1枚でも上下が逆になると、その1枚の電圧が差し引かれてしまい、合計電圧が下がります。

#### 手順

1. **TEG 6枚を横一列に並べます。**
   すべてのTEGの印字面（文字がある面）を上向きに統一します。

2. **隣同士の TEG を「黒線（ー）→ 赤線（＋）」の順で繋いでいきます。**

```text
  TEG1        TEG2        TEG3        TEG4        TEG5        TEG6
  赤  黒 ──── 赤  黒 ──── 赤  黒 ──── 赤  黒 ──── 赤  黒 ──── 赤  黒
  │                                                                │
  │                                                                │
  ▼                                                                ▼
 全体の (+)                                                  全体の (-)
 昇圧モジュール VIN+ へ                               昇圧モジュール GND へ
```

3. **繋ぎ方の詳細（5箇所の接続）:**

| 接続番号 | 繋ぐ線 | 繋ぐ相手 | 方法 |
| :---: | :--- | :--- | :--- |
| ① | TEG1 の **黒線(-)** | TEG2 の **赤線(+)** | ハンダ付けまたはワニ口クリップ |
| ② | TEG2 の **黒線(-)** | TEG3 の **赤線(+)** | 同上 |
| ③ | TEG3 の **黒線(-)** | TEG4 の **赤線(+)** | 同上 |
| ④ | TEG4 の **黒線(-)** | TEG5 の **赤線(+)** | 同上 |
| ⑤ | TEG5 の **黒線(-)** | TEG6 の **赤線(+)** | 同上 |

4. **最終的に残るのは2本の線だけです：**
   * **TEG1 の赤線(+)** → 昇圧モジュールの **VIN+** へ
   * **TEG6 の黒線(-)** → 昇圧モジュールの **GND** へ

> [!TIP]
> **接続のコツ:**
> - ハンダ付けが一番確実ですが、ワニ口クリップやねじり接続でもOKです。
> - 接続部分にはビニールテープなどを巻いて、金属がむき出しにならないようにしましょう（ショート防止）。
> - ブレッドボードに直接挿せない場合は、ジャンパワイヤの先端にハンダ付けしてください。

### 3-3. ヒートシンク（放熱板）の取り付け

温度差を効率よく作るため、TEGの **冷やす面（下側）** にヒートシンクを取り付けます。

```text
   ☀️ 温かいもの（お湯マグカップ・手のひら等）
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   ┃  TEG1  ┃  TEG2  ┃  TEG3  ┃  TEG4  ┃  TEG5  ┃  TEG6  ┃  ← 印字面（上）
   ┗━━━━━━━━┻━━━━━━━━┻━━━━━━━━┻━━━━━━━━┻━━━━━━━━┻━━━━━━━━┛
   ┌────────┐┌────────┐┌────────┐┌────────┐┌────────┐
   │ ヒート ││ ヒート ││ ヒート ││ ヒート ││ ヒート │  ← ヒートシンク5枚
   │ シンク ││ シンク ││ シンク ││ シンク ││ シンク │    (6枚目は無くてもOK)
   └────────┘└────────┘└────────┘└────────┘└────────┘
   ❄️ 冷たいもの（保冷剤・アイスパック・机の上等）
```

> [!TIP]
> **ヒートシンクが5枚しかない場合:**
> 6枚目のTEGはヒートシンクなしで机の表面に直置きでも問題ありません。
> テーブルの表面自体が放熱板の代わりになります。
>
> **熱伝導グリス（シリコングリス）** があれば、TEGとヒートシンクの間に薄く塗ると密着度が上がり、発電量がアップします。

## 4. USB昇圧モジュールの準備

### 4-1. モジュールの確認

お手元の「DC-DC USB 0.9V-5V に 5V 電圧変換ステップアップブースターモジュール」は、以下のような形をしています：

```text
  ┌──────────────────────────────────────┐
  │  DC-DC USB 0.9V-5V → 5V 昇圧モジュール  │
  │                                      │
  │  ┌──────────────┐                    │
  │  │  USB-A メス  │ ← 出力（5V固定）    │
  │  │  端子（穴）  │   ここにUSBケーブルを挿す
  │  └──────────────┘                    │
  │                                      │
  │         基板の裏側・端に               │
  │        入力パッド（2つ）               │
  │        [VIN+]  [VIN-]                │
  └──────────────────────────────────────┘
```

**このモジュールの特徴:**

| 項目 | 内容 |
| :--- | :--- |
| 入力 | 基板上の **2つのパッド**（VIN+ と VIN-）にハンダ付けで接続 |
| 出力 | **USB-A メス端子**（穴の形状）から 5V 固定出力 |
| 出力電圧 | **5V 固定**（調整ネジはありません） |

> [!NOTE]
> **5V 固定出力で問題ありません！** 理由：
> - スーパーキャパシタの定格は 5.5V なので、5V 充電は安全です。
> - ダイオード D2 を通過すると約 0.3V 下がり、VCC_node には約 4.7V が届きます。これは USB 接続時と**同じ電圧**です。
> - VSTORE の分圧（10kΩ/10kΩ）で GPIO4 に届く電圧は 5V ÷ 2 = 2.5V で、ADC の上限（3.3V）以内です。

### 4-2. USBケーブルの加工（出力の取り出し）

このモジュールの出力は USB-A メス端子なので、ブレッドボードに直接挿すことができません。
**不要な USB ケーブルを1本加工して、出力を取り出します。**

#### 用意するもの
- 不要な USB ケーブル 1本（USB-A オス端子があるもの。充電専用ケーブルでOK）
- ハサミまたはニッパー
- ワイヤーストリッパー（なければカッターナイフで慎重に被覆をむく）

#### 手順

1. **USB ケーブルの「USB-A オス端子」ではない方の端を、ハサミで切断します。**

```text
  [USB-A オス端子] ─────────── ✂️ ここで切る ─── [もう片方の端子]
       │                                           (不要)
   この端子を昇圧モジュールに挿す
```

2. **切断した側の被覆を 3cm ほどむきます。**
   中から **4本の細い線** が出てきます。

```text
   外側の被覆をむくと...

   🔴 赤色の線  = +5V（電源プラス）  ← ★これを使う
   ⚫ 黒色の線  = GND（電源マイナス） ← ★これを使う
   🟢 緑色の線  = データ線            ← 使わない（テープで絶縁）
   ⚪ 白色の線  = データ線            ← 使わない（テープで絶縁）
```

3. **赤色と黒色の線だけを残し、各線の先端を 1cm ほどむきます。**
   緑色と白色の線はビニールテープで先端を巻いて絶縁してください。

4. **むき出しになった赤色・黒色の線の先端に、ジャンパワイヤ（オス）をハンダ付けします。**
   （※ハンダ付けが難しい場合は、ねじり接続＋ビニールテープでもOKです）

> [!TIP]
> **ジャンパワイヤをハンダ付けしておくと、ブレッドボードに直接挿せるようになります！**

5. **完成した出力ケーブルの接続先：**

| ケーブルの線 | 接続先 |
| :--- | :--- |
| **赤色の線（+5V）** | ブレッドボードの **VSTORE 列**（スーパーキャパシタの＋側・D2アノード側） |
| **黒色の線（GND）** | ブレッドボードの **上部青ライン（GND）** |

### 4-3. 入力側の接続

昇圧モジュール基板の入力パッドに、TEG直列の出力線を接続します。

| 入力パッド | 接続するもの |
| :--- | :--- |
| **VIN+**（プラス側パッド） | TEG1 の **赤線(+)**（全体のプラス） |
| **VIN-**（マイナス側パッド） | TEG6 の **黒線(-)**（全体のマイナス） |

> [!NOTE]
> 入力パッドへの接続はハンダ付けが最も確実です。
> TEGの線を直接パッドにハンダ付けするか、ジャンパワイヤを経由してください。

### 4-4. 出力電圧の事前確認

ブレッドボードに繋ぐ**前に**、昇圧モジュール単体で出力を確認します。

1. 入力側に TEG直列（温度差あり）または乾電池 1本（1.5V）を接続します。
2. USB-A メス端子に加工済みの USB ケーブルを挿します。
3. テスター（`DCV 20`）で赤色の線と黒色の線の間の電圧を測ります。
4. **`4.8V` ～ `5.2V`** が表示されれば正常です！ ✅

## 5. ブレッドボード上の全体配線

### 5-1. 回路の全体像

```text
                                ┌──────────────────────────┐
                                │                          │
  TEG×6枚 ──→ [USB昇圧] ──→ [D2 ダイオード] ──→ 上部赤ライン(VCC_node)
  (直列接続)   (0.9V→5V)      (1N5819)            │
                                                   ├──→ XIAO 3V3
               [USB 5V] ──→ [D1 ダイオード] ─────→│
                               (1N5819)            │
                                                   ├──→ [100μF コンデンサ] ──→ GND
                                                   │
                                                   ├──→ [DS18B20 赤線×2]
                                                   │
                                                   └──→ [4.7kΩプルアップ]

  TEG×6枚 の GND ──→ 上部青ライン(GND) ←── XIAO GND
                              │
                              ├──→ [スーパーキャパシタ (-)脚]
                              ├──→ [100μF コンデンサ (-)脚]
                              └──→ [DS18B20 黒線×2]

  [USB昇圧 → USBケーブル赤線(+5V)] ──→ [スーパーキャパシタ (+)脚] ← ★ここが VSTORE
                                              │
                                              ├──→ [100Ω] ──→ 緑LED ──→ MOSFET Drain
                                              └──→ [10kΩ分圧] ──→ GPIO4 ──→ [10kΩ] ──→ GND

  [USB昇圧 → USBケーブル黒線(GND)] ──→ 上部青ライン(GND)
```

### 5-2. CJMCU-3108 との違い（配線変更点）

元の構成から変更するのは **2箇所だけ** です！

| 項目 | 元の構成（CJMCU-3108） | 今回の構成（USB昇圧） |
| :--- | :--- | :--- |
| **入力** | TEG 1枚 → CJMCU-3108 の VIN+ / GND | TEG 6枚直列 → USB昇圧モジュールの VIN+ / VIN- パッド |
| **D2 ダイオードの接続先** | CJMCU-3108 の VOUT ピン | USBケーブルの **赤線（+5V）** |
| **スーパーキャパシタ(+)の接続先** | CJMCU-3108 の VSTORE ピン | USBケーブルの **赤線（+5V）** |
| **出力GNDの接続** | CJMCU-3108 の GND ピン | USBケーブルの **黒線（GND）** → 上部青ライン |

> [!IMPORTANT]
> 元の CJMCU-3108 では「VOUT」と「VSTORE」が別々のピンでしたが、
> USB昇圧モジュールでは **USBケーブルの赤線（+5V）1本だけ** が出力です。
> したがって、**スーパーキャパシタの(+)脚** と **ダイオード D2 のアノード** は、
> どちらも USBケーブルの **赤線（+5V）** と同じブレッドボード列に繋ぎます。

## 7. 動作テスト

### テスト1: USB昇圧モジュール単体テスト（TEG＋昇圧のみ）

ブレッドボードに繋ぐ前に、昇圧モジュールが正しく動くか単体で確認します。

1. TEG6枚直列に温度差を与えます（上にお湯、下に保冷剤）。
2. USB-A メス端子に加工済みの USB ケーブルを挿します。
3. テスター（`DCV 20`）でUSBケーブルの **赤線** と **黒線** の間の電圧を測定します。
4. **`4.8V` ～ `5.2V`** が安定して出ていれば成功です！ ✅

### テスト2: スーパーキャパシタの充電テスト

1. USBケーブルの赤線（+5V）をスーパーキャパシタの長足(+)へ、黒線(GND)を短足(-)へ繋ぎます。
2. 温度差を与えると、テスター（`DCV 20`）でスーパーキャパシタの電圧が **じわじわと上昇** していきます。
3. **`2.5V` 以上** まで上がれば、蓄電成功です！ ✅

### テスト3: 全体テスト（USB接続してシリアルモニタ確認）

1. チェックリストの全項目を確認済みの状態で、USBケーブル（パソコン接続用）をマイコンに接続します。
2. Arduino IDE のシリアルモニター（115200 baud）を開きます。
3. TEGに温度差を与えます。
4. シリアルモニタで以下を確認します：
   - `V_store_mV` が **上昇** していく → ✅ 蓄電成功！
   - `deltaT_C` が **10℃以上** → ✅ 十分な温度差！
   - `flash_count` が **1以上** になる → ✅ 緑LEDが点灯（悪魔が仕事をしている）！

## 8. トラブルシューティング

| 症状 | 考えられる原因 | 対処法 |
| :--- | :--- | :--- |
| USBケーブルの赤線・黒線から電圧が出ない | TEGの温度差が不足（入力電圧が0.9V未満） | お湯の温度を上げる / 保冷剤を追加する / TEGの枚数を増やす |
| USBケーブルの赤線・黒線から電圧が出ない | TEGの直列接続で1枚の極性が逆 | 全TEGの赤線(+)と黒線(-)の向きを再確認 |
| USBケーブルの赤線・黒線から電圧が出ない | USBケーブルの赤線・黒線が断線している | 別のUSBケーブルで試す / テスターの導通モードで赤線・黒線の断線を確認 |
| `V_store_mV` が 220mV 前後で変わらない | 分圧抵抗（10kΩ×2）がフローティング | 上段10kΩがスーパーキャパシタ(+)に、下段10kΩがGNDに繋がっているか確認 |
| `V_store_mV` が上がるが緑LEDが光らない | MOSFET の Gate配線の問題 | GPIO3 → 220Ω → Gate、Gate → 10kΩ → GND を確認 |
| DS18B20 が `-127.0℃` を返す | OneWire 配線不良 | 4.7kΩプルアップ抵抗が GPIO2 と VCC_node 間に接続されているか確認 |
| テスターで TEG直列の電圧を測ると「マイナス」が出る | 温める面と冷やす面が逆 | お湯と保冷剤の位置を上下逆にする |
