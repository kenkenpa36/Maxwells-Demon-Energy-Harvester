# 組み立てマニュアル — 構成D改: TEG直列＋汎用昇圧モジュール版

> **このマニュアルの目的:**
> 初期不良だった CJMCU-3108（LTC3108搭載）モジュールの代わりに、
> **ペルチェ素子（TEG）6枚の直列接続** ＋ **汎用 0.9V DC-DC昇圧モジュール** を使って
> Maxwell's Demon Energy Harvester（構成D）を動作させる手順書です。

> [!IMPORTANT]
> **ファームウェア（プログラム）の変更は一切不要です。**
> 既存の `maxwell_demon_harvester_esp32c3.ino` がそのまま動作します。

## 1. 仕組みの違い

### 元の構成（CJMCU-3108 / LTC3108）

```text
TEG 1枚 (20〜50mV) ──→ [LTC3108 昇圧IC] ──→ 3.3V出力 ──→ スーパーキャパシタ蓄電
                        (20mVから昇圧可能な
                         特殊な超低電圧昇圧IC)
```

### 今回の代替構成（TEG直列 ＋ 汎用昇圧モジュール）

```text
TEG 6枚直列 (0.9V〜3V) ──→ [汎用 DC-DC昇圧] ──→ 3.3V出力 ──→ スーパーキャパシタ蓄電
                             (0.9V以上で起動する
                              一般的な昇圧モジュール)
```

#### なぜ 6枚直列にするのか？

ペルチェ素子（TEG）1枚が生み出す電圧は、温度差10℃のとき約 **150mV〜200mV** です。
汎用昇圧モジュールは **0.9V 以上** ないと起動しません。

| TEG枚数 | 温度差10℃での発電電圧 | 温度差20℃での発電電圧 | 汎用昇圧モジュール |
| :---: | :---: | :---: | :---: |
| 1枚 | 約 0.15V〜0.2V | 約 0.3V〜0.4V | ❌ 起動不可 |
| 2枚 | 約 0.3V〜0.4V | 約 0.6V〜0.8V | ❌ ギリギリ不足 |
| 4枚 | 約 0.6V〜0.8V | 約 1.2V〜1.6V | ⚠️ 温度差大なら可 |
| **6枚** | **約 0.9V〜1.2V** | **約 1.8V〜2.4V** | **✅ 安定起動！** |

6枚直列にすることで、温度差10℃でも **0.9V〜1.2V** の電圧が得られ、汎用昇圧モジュールが安定して起動します！

## 3. TEG 6枚の直列接続

### 3-1. 直列接続とは？

乾電池を並べて繋ぐのと同じ原理です。
1個1.5Vの乾電池を2本直列にすると3Vになるように、
TEGも直列に繋ぐと **電圧が足し算** されます。

```text
     ┌──── TEG1 ────┐   ┌──── TEG2 ────┐         ┌──── TEG6 ────┐
     │  赤(+) 黒(-) │   │  赤(+) 黒(-) │  ・・・  │  赤(+) 黒(-) │
     └───┬──────┬───┘   └───┬──────┬───┘         └───┬──────┬───┘
         │      └───────────┘      └── ・・・ ──────┘      │
         │    （黒と赤を繋ぐ）    （黒と赤を繋ぐ）          │
         │                                                  │
    ここが全体の           ここが全体の
     プラス(+)              マイナス(-)
    昇圧モジュール          昇圧モジュール
     VIN+ へ                 GND へ
```

### 3-2. 具体的な繋ぎ方（6枚の場合）

> [!CAUTION]
> **すべてのTEGの「温める面」と「冷やす面」の向きを統一してください！**
> 1枚でも上下が逆になると、その1枚の電圧が差し引かれてしまい、合計電圧が下がります。

#### 手順

1. **TEG 6枚を横一列に並べます。**
   すべてのTEGの印字面（文字がある面）を上向きに統一します。

2. **隣同士の TEG を「黒線（ー）→ 赤線（＋）」の順で繋いでいきます。**

```text
  TEG1        TEG2        TEG3        TEG4        TEG5        TEG6
  赤  黒 ──── 赤  黒 ──── 赤  黒 ──── 赤  黒 ──── 赤  黒 ──── 赤  黒
  │                                                                │
  │                                                                │
  ▼                                                                ▼
 全体の (+)                                                  全体の (-)
 昇圧モジュール VIN+ へ                               昇圧モジュール GND へ
```

3. **繋ぎ方の詳細（5箇所の接続）:**

| 接続番号 | 繋ぐ線 | 繋ぐ相手 | 方法 |
| :---: | :--- | :--- | :--- |
| ① | TEG1 の **黒線(-)** | TEG2 の **赤線(+)** | ハンダ付けまたはワニ口クリップ |
| ② | TEG2 の **黒線(-)** | TEG3 の **赤線(+)** | 同上 |
| ③ | TEG3 の **黒線(-)** | TEG4 の **赤線(+)** | 同上 |
| ④ | TEG4 の **黒線(-)** | TEG5 の **赤線(+)** | 同上 |
| ⑤ | TEG5 の **黒線(-)** | TEG6 の **赤線(+)** | 同上 |

4. **最終的に残るのは2本の線だけです：**
   * **TEG1 の赤線(+)** → 昇圧モジュールの **VIN+** へ
   * **TEG6 の黒線(-)** → 昇圧モジュールの **GND** へ

> [!TIP]
> **接続のコツ:**
> - ハンダ付けが一番確実ですが、ワニ口クリップやねじり接続でもOKです。
> - 接続部分にはビニールテープなどを巻いて、金属がむき出しにならないようにしましょう（ショート防止）。
> - ブレッドボードに直接挿せない場合は、ジャンパワイヤの先端にハンダ付けしてください。

### 3-3. ヒートシンク（放熱板）の取り付け

温度差を効率よく作るため、TEGの **冷やす面（下側）** にヒートシンクを取り付けます。

```text
   ☀️ 温かいもの（お湯マグカップ・手のひら等）
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   ┃  TEG1  ┃  TEG2  ┃  TEG3  ┃  TEG4  ┃  TEG5  ┃  TEG6  ┃  ← 印字面（上）
   ┗━━━━━━━━┻━━━━━━━━┻━━━━━━━━┻━━━━━━━━┻━━━━━━━━┻━━━━━━━━┛
   ┌────────┐┌────────┐┌────────┐┌────────┐┌────────┐
   │ ヒート ││ ヒート ││ ヒート ││ ヒート ││ ヒート │  ← ヒートシンク5枚
   │ シンク ││ シンク ││ シンク ││ シンク ││ シンク │    (6枚目は無くてもOK)
   └────────┘└────────┘└────────┘└────────┘└────────┘
   ❄️ 冷たいもの（保冷剤・アイスパック・机の上等）
```

> [!TIP]
> **ヒートシンクが5枚しかない場合:**
> 6枚目のTEGはヒートシンクなしで机の表面に直置きでも問題ありません。
> テーブルの表面自体が放熱板の代わりになります。
>
> **熱伝導グリス（シリコングリス）** があれば、TEGとヒートシンクの間に薄く塗ると密着度が上がり、発電量がアップします。

## 4. 汎用昇圧モジュールの準備と出力電圧調整

### 4-1. モジュールの確認

お手元の「0.9V〜5V DC-DC昇圧モジュール」には、通常以下の **4つの端子** があります：

```text
  ┌──────────────────────────────┐
  │   0.9V〜5V DC-DC 昇圧モジュール  │
  │                              │
  │   ┌──┐  ← 小さなネジ（ポテンショメーター / 可変抵抗）
  │   │⊕│     出力電圧を調整するためのネジです
  │   └──┘                       │
  │                              │
  │  [VIN+]  [VIN-]  [VOUT+]  [VOUT-]  │
  └──────────────────────────────┘
       │       │       │        │
       │       │       │        │
    入力の   入力の   出力の    出力の
    プラス   マイナス  プラス   マイナス
```

> [!NOTE]
> **端子の表記はモジュールによって異なる場合があります。**
> - `VIN-` は `GND` や `IN-` と書かれていることがあります。
> - `VOUT-` は `GND` や `OUT-` と書かれていることがあります。
> - 入力側と出力側の **GND（マイナス）** は、モジュール内部で繋がっているものが多いです。

### 4-2. 出力電圧の調整（超重要！必ず最初に行う）

> [!CAUTION]
> **必ず昇圧モジュールをブレッドボードに繋ぐ前に、出力電圧を調整してください！**
> 調整せずに繋ぐと、高い電圧がマイコンに加わって壊れる恐れがあります。

#### 手順

1. **TEG 直列 6枚（または乾電池1本: 1.5V）を昇圧モジュールの入力に繋ぎます。**
   - TEG全体の **赤線(+)** → モジュールの **VIN+**
   - TEG全体の **黒線(-)** → モジュールの **VIN-** (GND)
   - ※乾電池を使う場合: プラス(+) → VIN+、マイナス(-) → VIN-

2. **温度差を与えます（TEGの場合）。**
   - 上にお湯、下に氷（保冷剤）を当てて、TEGに温度差を作ります。

3. **テスター（DT-830D）で出力電圧を測定します。**
   - ダイヤル: **`DCV 20`**
   - **赤プローブ**: モジュールの **VOUT+**
   - **黒プローブ**: モジュールの **VOUT-** (GND)

4. **小さなネジ（ポテンショメーター）をマイナスドライバーで回します。**
   - テスターの数値を見ながら、**`3.3V` ～ `3.5V`** の範囲になるように調整します。
   - 大抵は**反時計回りに回すと電圧が下がり、時計回りに回すと上がります**（モジュールによって逆の場合あり）。
   - ⚠️ 一気にたくさん回さず、少しずつ回しながら電圧を確認してください。

5. **出力電圧が安定して `3.3V` ～ `3.5V` を示していれば、調整完了です！** ✅

> [!WARNING]
> **絶対に `5.0V` を超えないでください！**
> ESP32-C3 の電源定格は 3.3V です。5V を超えるとマイコンが故障します。
> ダイオードD2経由で電圧降下があるため、**`3.3V` ～ `3.5V`** に設定するのが最適です。

## 5. ブレッドボード上の全体配線

### 5-1. 回路の全体像

```text
                              ┌──────────────────────────┐
                              │                          │
  TEG×6枚 ──→ [汎用昇圧] ──→ [D2 ダイオード] ──→ 上部赤ライン(VCC_node)
  (直列接続)   (0.9V→3.3V)     (1N5819)            │
                                                    ├──→ XIAO 3V3
               [USB 5V] ──→ [D1 ダイオード] ──────→│
                               (1N5819)             │
                                                    ├──→ [100μF コンデンサ] ──→ GND
                                                    │
                                                    ├──→ [DS18B20 赤線×2]
                                                    │
                                                    └──→ [4.7kΩプルアップ]
                                                    
  TEG×6枚 の GND ──→ 上部青ライン(GND) ←── XIAO GND
                              │
                              ├──→ [スーパーキャパシタ (-)脚]
                              ├──→ [100μF コンデンサ (-)脚]
                              └──→ [DS18B20 黒線×2]

  [汎用昇圧 VOUT+] ─────────→ [スーパーキャパシタ (+)脚]  ← ★ここが VSTORE
                                      │
                                      ├──→ [100Ω] ──→ 緑LED ──→ MOSFET Drain
                                      └──→ [10kΩ分圧] ──→ GPIO4 ──→ [10kΩ] ──→ GND
```

### 5-2. CJMCU-3108 との違い（配線変更点）

元の構成から変更するのは **2箇所だけ** です！

| 項目 | 元の構成（CJMCU-3108） | 今回の構成（汎用昇圧） |
| :--- | :--- | :--- |
| **入力** | TEG 1枚 → CJMCU-3108 の VIN+ / GND | TEG 6枚直列 → 汎用昇圧モジュールの VIN+ / VIN- |
| **D2 ダイオードの接続先** | CJMCU-3108 の VOUT ピン | 汎用昇圧モジュールの **VOUT+** |
| **スーパーキャパシタ(+)の接続先** | CJMCU-3108 の VSTORE ピン | 汎用昇圧モジュールの **VOUT+** |

> [!IMPORTANT]
> 元の CJMCU-3108 では「VOUT」と「VSTORE」が別々のピンでしたが、
> 汎用昇圧モジュールでは **「VOUT+」1つだけ** です。
> したがって、**スーパーキャパシタの(+)脚** と **ダイオード D2 のアノード** は、
> どちらも汎用昇圧モジュールの **VOUT+** に繋ぎます。

## 8. トラブルシューティング

| 症状 | 考えられる原因 | 対処法 |
| :--- | :--- | :--- |
| 昇圧モジュールの出力が 0V のまま | TEGの温度差が不足（入力電圧が0.9V未満） | お湯の温度を上げる / 保冷剤を追加する / TEGの枚数を増やす |
| 昇圧モジュールの出力が 0V のまま | TEGの直列接続で1枚の極性が逆 | 全TEGの赤線(+)と黒線(-)の向きを再確認 |
| 出力電圧が `3.3V` にならない | ポテンショメーター（ネジ）の調整不足 | マイナスドライバーで少しずつ回して調整 |
| `V_store_mV` が 220mV 前後で変わらない | 分圧抵抗（10kΩ×2）がフローティング | 上段10kΩがスーパーキャパシタ(+)に、下段10kΩがGNDに繋がっているか確認 |
| `V_store_mV` が上がるが緑LEDが光らない | MOSFET の Gate配線の問題 | GPIO3 → 220Ω → Gate、Gate → 10kΩ → GND を確認 |
| DS18B20 が `-127.0℃` を返す | OneWire 配線不良 | 4.7kΩプルアップ抵抗が GPIO2 と VCC_node 間に接続されているか確認 |
| テスターで TEG直列の電圧を測ると「マイナス」が出る | 温める面と冷やす面が逆 | お湯と保冷剤の位置を上下逆にする |
